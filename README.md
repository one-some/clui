## Claire's Editor
A code editor built from scratch. Depends on RayLib for drawing primitives and text, and depends on some of the standard library until I implement the rest.

<p align="center">
    <img src="https://github.com/one-some/clui/blob/master/static/screenshot.png?raw=true" alt="Day" width="600">
</p>

### Features
* Tabs
* Vim bindings
* Integrated terminal emulator
* LSP issue reporting with clangd 
* Syntax highlighting
* Custom standard library
* JSON serializer/deserializer
